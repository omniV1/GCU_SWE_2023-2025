## Logistic Regression

> [!summary] Definition
> Logistic regression is a **supervised-learning parametric classification model**.
> It is generally the first thing to try when building a classifier.

### Key Terminology

| Term | Definition |
|------|------------|
| **Parametric Model** | A model fit with a **fixed number of parameters**, regardless of data size. (Non-parametric models can be arbitrarily complex based on data) |
| **Soft Classifier** | Predicts **probabilities** for each class (logistic regression does this) |
| **Hard Classifier** | Only predicts the class label, not probabilities |

### Why Use Logistic Regression First?

1. **Fast** - quick training and prediction
2. **Simple** - few hyperparameters to tune
3. **Interpretable** - coefficients have clear meaning
4. **Good probabilities** - outputs are well-calibrated

### Advantages vs Disadvantages

| Advantages                   | Disadvantages                                                    |
| ---------------------------- | ---------------------------------------------------------------- |
| Fast (training & prediction) | Requires feature engineering to capture non-linear relationships |
| Simple (few hyperparameters) | Doesn't work for $p > n$ (more features than samples)            |
| Interpretable                |                                                                  |
| Provides good probabilities  |                                                                  |

> [!warning] When Logistic Regression Fails
> When $p > n$ (more features than observations), logistic regression struggles because there are infinitely many solutions that perfectly separate the data.

# Lecture 1: Introduction to Classification

## Maximum Likelihood Estimation (MLE)

> [!question] What is MLE?
> A method to find the parameter values that maximize the likelihood of observing the given data.

### What is a Loss Function?

> [!info] Loss Function Purpose
> A loss function measures **how poorly** the model performs (how "bad" our predictions are).
> We find optimal parameters by **minimizing** the loss function.

### Comparison to Linear Regression

Recall that with linear regression we created a model:

$$\hat{y} = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + ... + \beta_p X_p = X\beta$$

We found the "best" line by minimizing a **loss function** (sum of squared residuals):

$$\text{Loss} = \sum_i (y_i - \hat{y}_i)^2$$

### MLE Formulation for Classification

For linear regression:
$$Y \sim N(X\beta, \sigma)$$

For classification, we change our approach:
$$Y \sim \text{Bernoulli}(f(X\beta))$$

Where $f$ is a **sigmoid function** (values from 0 to 1). We choose the **logistic function**:

$$f(x) = \frac{1}{1 + e^{-x}}$$

## Log Odds Ratio

> [!info] Understanding Odds
> - **Odds of 3:1** → 75% chance of winning ($P = 3/(3+1) = 0.75$)
> - **Odds of 4:1** → 80% chance of winning ($P = 4/(4+1) = 0.80$)
> - **Odds of 1:1** → Even odds (50%)
> - **Odds of 1:3** → 25% chance
> - **Odds of 1:4** → 20% chance

### Formula

$$\text{Odds Ratio (OR)} = \frac{P(y=1)}{1 - P(y=1)}$$

$$P(y=1) = \frac{OR}{1 + OR}$$

### Converting Probability to Odds

| Probability | Odds  | Log Odds |
|-------------|-------|----------|
| P = 0.5     | 1:1   | 0        |
| P = 0.75    | 3:1   | 1.1      |
| P = 0.8     | 4:1   | 1.39     |
| P = 0.2     | 1:4   | -1.39    |

> [!note] Key Point
> When $P(y=1) = 0.5$, the odds are 1:1, and **log(odds) = 0**

### The Math

For logistic regression:

$$P(y=1) = \frac{1}{1 + e^{-X\beta}}$$

Therefore:

$$\text{OR} = e^{X\beta}$$

$$\log(\text{OR}) = X\beta$$

> [!important] Key Insight
> If you increase $X_i$ by 1, you increase $\log(\text{OR})$ by $\beta_i$

## Evaluating Classification Models

### Confusion Matrix

| | Predicted Positive | Predicted Negative |
|---|---|---|
| **Actual Positive** | True Positive (TP) | False Negative (FN) |
| **Actual Negative** | False Positive (FP) | True Negative (TN) |

### Key Metrics

| Metric | Formula | Description |
|--------|---------|-------------|
| **Accuracy** | $\frac{TP + TN}{TP + TN + FP + FN}$ | Overall proportion correctly classified |
| **Precision** | $\frac{TP}{TP + FP}$ | Of predicted positives, how many are correct? |
| **Recall (Sensitivity/TPR)** | $\frac{TP}{TP + FN}$ | Of actual positives, how many were found? |
| **Specificity (TNR)** | $\frac{TN}{TN + FP}$ | Of actual negatives, how many were correct? (True Negative Rate) |
| **F1-Score** | $\frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$ | **Harmonic mean** of precision and recall |

> [!tip] Memory Trick
> - **Precision:** "Of my predictions, how many were right?" (TP in numerator, predicted positives in denominator)
> - **Recall:** "Of the actual positives, how many did I catch?" (TP in numerator, actual positives in denominator)

# Lecture 2: Model Evaluation & MLE Deep Dive

## ROC Curve and AUC

> [!summary] ROC Curve
> - **X-axis:** False Positive Rate (1 - Specificity)
> - **Y-axis:** True Positive Rate (Recall/Sensitivity)
> - **AUC:** Area Under the Curve (closer to 1 = better)

### What Does AUC Represent?

> [!important] AUC Interpretation
> AUC = the **probability that the model ranks a randomly chosen positive instance higher than a randomly chosen negative instance**.

| AUC Value | Interpretation |
|-----------|----------------|
| **0.5**   | Random classifier (diagonal line) - no discrimination |
| **0.7-0.8** | Acceptable discrimination |
| **0.8-0.9** | Excellent discrimination |
| **1.0**   | Perfect classifier |

## Multicollinearity

### Variance Inflation Factor (VIF)

> [!info] What is VIF?
> **VIF = Variance Inflation Factor** - a measure of how much the variance of a coefficient is inflated due to correlation with other features.

**Formula:**
$$\text{VIF} = \frac{1}{1 - R^2}$$

Where $R^2$ is obtained by **regressing that feature on all other features**.

> [!warning] Rule of Thumb
> - **VIF > 5:** Moderate multicollinearity (caution)
> - **VIF > 10:** High multicollinearity (problematic - consider removing feature)

## MLE for Logistic Regression (Detailed)

### Likelihood Function

For a single Bernoulli trial with outcome $y$:

$$P(y|p) = p^y (1-p)^{1-y}$$

For $n$ independent trials:

$$L(p|y_1, y_2, ..., y_n) = \prod_{i=1}^{n} p^{y_i}(1-p)^{1-y_i}$$

If $k$ = number of successes:

$$L(p) = p^k (1-p)^{n-k}$$

### Log-Likelihood

$$\ln(L) = k\ln(p) + (n-k)\ln(1-p)$$

> [!question] Why Log-Likelihood Instead of Likelihood?
> Taking the log **converts products to sums**, which is:
> 1. **Computationally easier** - addition is simpler than multiplication
> 2. **More numerically stable** - avoids very small numbers from multiplying many probabilities

## Gradient Descent (Newton's Method)

> [!info] Newton-Raphson Method
> An iterative root-finding algorithm using tangent lines to approximate roots.

### Algorithm Steps

1. **Start** with initial guess $x_0$
2. **Find** point on function: $(x_0, f(x_0))$
3. **Draw** tangent line at that point
4. **Find** where tangent crosses x-axis → new guess $x_1$
5. **Repeat** until convergence

### Update Formula

$$x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)}$$

> [!tip] Why It Works
> The tangent line provides a linear approximation of the function, guiding us toward where $f(x) = 0$
