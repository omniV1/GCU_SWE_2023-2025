# Commonly Reported Amazon OA Themes (2025-2026)

Based on candidate-reported summaries and prep writeups, the most repeated OA shapes are:

## Highest frequency
- Arrays/Hashing (pairing, counting, grouping, frequency sort)
- Sliding Window (longest/shortest subarray/substring constraints)
- Two Pointers (in-place transforms, subsequence checks)
- Graph/Grid BFS/DFS (islands, shortest path, connected components)
- Sorting + Greedy (interval merge, scheduling, tie-break ranking)

## Medium frequency
- Heap/Priority Queue (top-k, assignment, streaming best)
- Binary Search on Answer (minimum feasible capacity/rate)
- Basic DP (word break, 1D decisions)

## Amazon-style shell forms (same underlying patterns)
- Priority sorting with tie-break rules
- Warehouse allocation / inventory assignment
- Bug or event log frequency ranking
- Server grouping/packing constraints
- Grid shortest path / region counting

## Interview note
Treat story statements as wrappers. Classify pattern in the first 2 minutes.
