Assignment Overview¶

This notebook follows the Jupyter Notebook Template used in the course. It documents the PCA workflow required to isolate influential employee performance indicators that inform bonus allocation and professional development planning.

  • Data source: WA_Fn-UseC_-HR-Employee-Attrition.csv (IBM HR Analytics dataset) located in ../Data/.
  • Scope: 1,470 employee records × 35 HR indicators. Although the assignment references datasets with 50,000+ rows, this is the official resource supplied in the course materials and is therefore analyzed as-is.
  • Goal: Reduce the correlated indicators to a smaller set of latent components, quantify their explanatory power, and deliver a PCA-based performance index on a 0–100 scale.

Each part mirrors the assignment instructions: Part I (preparation), Part II (assumption checks), and Part III (PCA execution, scoring, and interpretation).

Part I · Step 1 — Interpreting performance & predictors¶

Performance is observed through the provided PerformanceRating field and the latent constructs created through PCA. Predictors of performance include compensation signals (MonthlyIncome, PercentSalaryHike), engagement measures (JobInvolvement, RelationshipSatisfaction), tenure variables (TotalWorkingYears, YearsSinceLastPromotion), and workload indicators (OverTime, BusinessTravel). PCA will summarize these correlated inputs into orthogonal components that can guide bonus and development policy decisions.

def compute_corr_pvalues(df):
    '''Return a DataFrame of two-tailed p-values mirroring psych::corr.p().'''
    df = df.dropna()
    cols = df.columns
    pvals = pd.DataFrame(np.ones((len(cols), len(cols))), columns=cols, index=cols)
    np.fill_diagonal(pvals.values, 0.0)
    for i in range(len(cols)):
        for j in range(i + 1, len(cols)):
            r, p = stats.pearsonr(df.iloc[:, i], df.iloc[:, j])
            pvals.iloc[i, j] = pvals.iloc[j, i] = p
    return pvals


def bartlett_sphericity_test(corr_matrix, n_samples):
    p = corr_matrix.shape[0]
    sign, logdet = np.linalg.slogdet(corr_matrix)
    if sign <= 0:
        return np.nan, p * (p - 1) / 2, np.nan
    chi2 = -(n_samples - 1 - (2 * p + 5) / 6) * logdet
    dof = p * (p - 1) / 2
    p_value = stats.chi2.sf(chi2, dof)
    return chi2, dof, p_value


def kaiser_meyer_olkin(df):
    corr = df.corr().values
    inv_corr = np.linalg.pinv(corr)
    partial = -inv_corr / np.sqrt(np.outer(np.diag(inv_corr), np.diag(inv_corr)))
    np.fill_diagonal(partial, 0.0)
    corr_sq = np.square(corr)
    partial_sq = np.square(partial)
    np.fill_diagonal(corr_sq, 0.0)
    np.fill_diagonal(partial_sq, 0.0)
    kmo_num = np.sum(corr_sq)
    kmo_den = kmo_num + np.sum(partial_sq)
    overall = kmo_num / kmo_den
    per_item = np.sum(corr_sq, axis=0) / (np.sum(corr_sq, axis=0) + np.sum(partial_sq, axis=0))
    return overall, pd.Series(per_item, index=df.columns).sort_values(ascending=False)


def cronbach_alpha(df):
    df = df.dropna()
    k = df.shape[1]
    if k < 2:
        return np.nan
    item_var = df.var(axis=0, ddof=1)
    total_var = df.sum(axis=1).var(ddof=1)
    if np.isclose(total_var, 0.0):
        return np.nan
    return (k / (k - 1)) * (1 - item_var.sum() / total_var)


def to_0_100_scale(series):
    min_val, max_val = series.min(), series.max()
    if np.isclose(max_val, min_val):
        return pd.Series(np.full_like(series, 50.0), index=series.index)
    scaled = (series - min_val) / (max_val - min_val)
    return scaled * 100

target_variance = 0.85

pca = PCA(random_state=SEED)

component_labels = [f"PC{i+1}" for i in range(pca.n_components_)]
explained = pca.explained_variance_ratio_
eigenvalues = pca.explained_variance_

pca_results = pd.DataFrame({
    'component': component_labels,
    'eigenvalue': eigenvalues,
    'variance_pct': explained * 100,
    'cumulative_pct': np.cumsum(explained) * 100,
    'eigenvalue_gt1': eigenvalues > 1.0
})

  • Assumption checks: Bartlett's test decisively rejected the null of an identity matrix (χ² ≈ 35,172, p < 0.001). The KMO statistic of ~0.74 indicates middling-to-meritorious sampling adequacy, and the determinant (≈5.6e-5) stayed positive, so the correlation matrix is factorable.
  • Component decisions: The first 20 components explain ~87.34% of the variance (12.66% residual). Eigenvalues fall below 1 after PC9, flagging diminishing returns, but 20 components are required to reach the 85% variance target set for this analysis.
  • Key drivers: PC1 captures tenure and compensation signals (TotalWorkingYears, YearsAtCompany, JobLevel, MonthlyIncome, YearsInCurrentRole). Its Cronbach alpha (~0.889) shows strong internal consistency, making it a defensible latent bonus index.
  • Bonus index: The 0–100 scaled PC1 scores provide a ranked view of employees for bonus eligibility. Histograms show a slightly right-skewed distribution—most employees cluster around the middle, while high-tenure/high-income staff dominate the upper tail.
