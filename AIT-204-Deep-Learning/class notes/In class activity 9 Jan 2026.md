 # Differentiating 8x^4 + 3x using the Power Rule

  ## Power Rule
  d/dx [x^n] = n·x^(n-1)

  ## Problem
  Find d/dx [8x^4 + 3x]

  ## Solution

  ### Rewrite each term
  8x^4 + 3x^1

  ### Apply the power rule to each term

  **First term: 8x^4**
  4
  
   4 × 8 = 32
   
  x^(4-1) = x^3
  
  32x^3

  **Second term: 3x^1**
  
  1
  
  1 × 3 = 3
  
  x^(1-1) = x^0 = 1
  
  3

  ### Combine results

  **d/dx [8x^4 + 3x] = 32x^3 + 3**
