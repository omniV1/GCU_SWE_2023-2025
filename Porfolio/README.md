# Owen Lindsey — Software Engineering Portfolio

Personal portfolio for a full-stack software engineer focused on React,
TypeScript, Node.js, and ASP.NET Core. The site highlights production work,
client projects, aviation operations software, and selected ML coursework.

## Featured work

- **Lunara Care** — production postpartum care platform with scheduling,
  real-time chat, care plans, MFA, and 375 automated tests.
- **Turnover Log** — React and ASP.NET Core shift-handoff application based on
  real F-22 maintenance workflows.
- **Iron Palace Podcast** — client website that publishes YouTube episodes from
  an RSS-generated static data feed.
- **CineScope** — team-built Blazor and ASP.NET Core movie platform.

Live demos and source links are available from the Projects page.

## Stack

- React 18, TypeScript, Vite
- Tailwind CSS, MUI, Radix UI, Motion
- React Router
- Vercel deployment

## Local development

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Public resume policy

The deployed site contains one canonical software-engineering resume:
`public/Owen_Lindsey_Resume.pdf`. Employer-specific applications, cover letters,
and transcripts are intentionally excluded from version control.
