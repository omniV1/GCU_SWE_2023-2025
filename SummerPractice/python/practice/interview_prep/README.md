# FAANG Pattern Reboot Workspace

This folder turns your 6-week plan into a repeatable system.

## Start here
1. Solve warm-ups:
   - `../01_richest_customer.py`
   - `../02_max_consecutive_ones.py`
   - `../03_valid_palindrome.py`
2. Log every miss in `logs/mistake_log_template.csv`.
3. Run weekly tracks in order:
   - `plans/week1_2_core_patterns.md`
   - `plans/week3_4_data_structures.md`
   - `plans/week5_6_integration.md`
4. Run a weekly review with `plans/weekly_retrospective.md`.

## Tools included
- `logs/spaced_repetition_guide.md`: exact 1d/3d/7d/14d cadence.
- `logs/review_scheduler.py`: prints due reviews from your mistake log.
- `mocks/timed_practice_template.md`: one-sheet template for timed drills.
- `mocks/mock_scorecard.md`: structured scoring rubric for mock interviews.
