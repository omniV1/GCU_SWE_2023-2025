# Week 5-6 Integration: Mixed Sets and Mock Interviews

## Core objective
Convert pattern drills into interview performance by mixing topics and enforcing time + communication constraints.

## Weekly format
- 3 mixed-problem days (3 mediums/day across different patterns)
- 2 mock-interview days (2 mediums + explanation)
- 1 deep review day (only misses and slow passes)
- 1 light day (flashcards and verbal dry-runs)

## Mixed set construction rules
Each mixed set must include:
- one array/string problem
- one pointer/window or stack problem
- one tree/graph/heap or binary-search/DP problem

Avoid solving two problems from the same pattern back-to-back.

## Mock loop format (90 minutes)
1. 5 min: read prompt, clarify constraints.
2. 35 min: problem 1 timed solve.
3. 10 min: explain complexity/tradeoffs aloud.
4. 35 min: problem 2 timed solve.
5. 5 min: retrospective + log misses.

## Communication bar for each mock
- Clearly name pattern and invariant before coding.
- Narrate tradeoffs (speed, readability, space).
- State at least two edge cases before finalizing.
- End with complexity in big-O with one sentence justification.

## End-of-phase KPI targets
- >=70% success rate on mixed medium sets.
- <=35 minutes median solve time per medium.
- >=80% of mock explanations rated 4/5 or higher.
