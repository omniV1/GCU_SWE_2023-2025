## Timed practice protocol
1. 5 minutes: classify pattern + state invariants.
2. 25 minutes: code first complete attempt.
3. 5 minutes: test edge cases and complexity explanation.
4. Log result immediately in mistake log.

## Minimum end-of-phase bar
- >=70% first-pass on easy/medium set
- <=35 minutes average for medium solves
- verbal explanation with clear invariant and complexity every time
