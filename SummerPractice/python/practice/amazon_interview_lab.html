Amazon live-coding protocol (best + worst day)

Use this every Run — especially under pressure.

  • 0–2 min: Restate problem. Ask: empty? duplicates? n size? mutate?
  • 2–5 min: Name pattern out loud. State brute force + target Big-O.
  • 5–8 min: Write the invariant in one sentence before code.
  • Code: Narrate. If stuck >3 min, say so and simplify.
  • Before submit: Trace empty / single / duplicates on paper or in comments.
  • End: Time, space, one tradeoff.
Worst day: silent coding, skipping edges, fighting the interviewer, forgetting LP stories. This lab’s “Say this out loud” tab is your safety script.
Best day: pattern named fast, edges listed, collaborative when stuck, complexity crisp.
